Caption fonts for content videos (components/visuals/video-renderer.ts, docs/VIDEO_ROBOT.md), self-hosted so the
browser and the video robot draw the same captions without an outside CDN. Latin and Latin Extended subsets, woff2,
from Fontsource 5.3.0 (the version lib/designs/templates/fonts.ts uses for the slide designs). Which style uses which
family is STYLES[style].video in lib/designs/library/styles.ts: Inter, Playfair Display, Anton, Nunito, Poppins,
DM Serif Display and Space Grotesk. All under the SIL Open Font License 1.1: see the *-LICENSE.txt files next to them.
