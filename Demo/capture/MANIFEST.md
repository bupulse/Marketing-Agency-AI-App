## Not captured, and why
- **Admin console** (companies list, Client 360): /admin needs an ADMIN_EMAILS address with real TOTP two-factor (AAL2). I skipped it, as the brief said, without changing any security settings.
- **Store builder, ads manager, MoMo payment, admin approval, custom plan builder, RWF pricing**: these features don't exist in the app yet. The pricing page shows the current USD plans.
- **Real Instagram/Facebook OAuth**: not possible. The connections are database rows (see below).

## Things in the real UI you should know about
- The home page testimonials still hold placeholder text ("[Testimonial from a store owner]"), so I hid that section in the marketing captures. The hero illustration also shows placeholders ("[your.shop]", "[Product photo]", "[Visitor name]"). That is the real page, so I left it as it is.
- The dashboard "Designs: 0 Branded posts made" card is hard-coded to 0 in `app/dashboard/page.tsx` (line 52), so it reads 0 even when designs exist.
- "Install the chat widget" stays unticked on Nova's dashboard even though the widget ran on the test site.
- A possible Autopilot time-zone issue: for Africa/Kigali with posting times 09:00 and 18:00, the planner saved the posts at 09:00 and 18:00 **UTC** (11:00 and 20:00 Kigali). The code (`zonedToUtc` in lib/autopilot/planner.ts) looks right, so the cause may be the business time zone value at run time. Worth checking. For the demo, I moved those 14 posts back 2 hours (`fix-autopilot-times.mjs`) so the screens match the settings.
- Instagram previews crop square designs to 4:5. So I made a portrait (4:5) version of the main design for each business, and the Instagram posts use it.
