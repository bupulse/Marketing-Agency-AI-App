The Video Studio API

Everything the studio pages do goes through a small JSON API. You can call it yourself to quote, generate and fetch videos and images.

Keys come per business, in the app. Today the studio runs on this computer only (127.0.0.1, port 3100) and needs no key. When the studio joins BuPulse, each business gets its own API key in Settings, sent as Authorization: Bearer <key>, and spends that business's credits. The paths below stay the same.

How it works

  1. Quote the job (POST /api/quote) to see its credits.
  2. Upload any photo, video or audio you want as a reference.
  3. Submit: POST /api/seedance/submit for real video, POST /api/design for a motion video, POST /api/image for an image. Credits are taken when the job starts.
  4. Wait: Seedance jobs run 1 to 10 minutes; check GET /api/seedance/jobs/{id} every 10 seconds. Motion designs and images answer directly.
  5. Download the MP4 from videoUrl. A failed job gives its credits back by itself.

Base URL today: http://localhost:3100. All bodies are JSON (content-type: application/json) except uploads, which are the raw file bytes.

Credits

1 credit = 10 RWF. GET /api/pricing lists the packs and the price of every model; GET /api/wallet returns the balance.

GET /api/pricing
{
  "packs": [{ "id": "starter", "name": "Starter pack", "credits": 1000, "rwf": 10000 }, …],
  "seedance": [{ "tier": "fast", "name": "Seedance 2.0 Fast", "resolution": "720p", "credits5s": 190, "credits10s": 385, "credits15s": 575 }, …],
  "claudeCredits": 30,
  "presenterCredits": 15
}

Quote a price

POST /api/quote
{ "engine": "seedance", "tier": "fast", "resolution": "720p", "seconds": 5, "versions": 1 }

200 { "credits": 190, "usd": 0.6 }

engine: seedance or claude. tier: pro (Seedance 2.0), fast, mini. seconds: 4 to 15. versions: 1 to 4.

Upload references

POST /api/upload            (body: the photo bytes, content-type image/jpeg, png or webp; at most 15 MB)
200 { "id": "up-1a2b3c4d5e6f", "width": 1600, "height": 2000 }

POST /api/media             (body: MP4 / MOV video or MP3 / WAV audio; at most 60 MB)
200 { "id": "um-1a2b3c4d5e6f", "mimeType": "video/mp4", "bytes": 5242880 }

Use them in a job as up:<id> (photo) or um:<id> (video or audio). A product photo from BuPulse is ph:<assetId>; a video you made is vid:seedance:<jobId> or vid:claude:<jobId>. Photos of real people's faces are refused by Seedance.

Seedance video

POST /api/seedance/submit
{
  "prompt": "0-2 s: close-up of the phone from Image 1 turning on a wooden table; 2-5 s: a hand picks it up.",
  "refs": [{ "id": "ph:7f0c…", "kind": "image" }],
  "tier": "fast", "resolution": "720p", "ratio": "9:16", "seconds": 5,
  "audio": true, "fixedLens": false, "flex": false, "draft": false, "seed": null, "versions": 1
}

200 { "jobs": [{ "id": "sd-0a1b2c3d4e5f", "status": "queued", "credits": 190, "estimateUsd": 0.6, … }] }
503 { "error": "Seedance is waiting for the BytePlus key (SEEDANCE_API_KEY in .env)." }

Ratios: 9:16, 3:4, 1:1, 4:3, 16:9, 21:9, adaptive. Up to 9 images, 3 videos and 3 audio files; refer to them in the prompt as Image 1, Video 1, Audio 1. Image roles: first_frame, last_frame or reference_image. POST /api/seedance/prompt asks Claude to write the prompt from a product (businessId, productId, templateId).

Seedance jobs

GET /api/seedance/jobs/sd-0a1b2c3d4e5f
200 {
  "id": "sd-0a1b2c3d4e5f",
  "status": "succeeded",          // submitting | queued | running | succeeded | failed | cancelled
  "videoFile": "sd-0a1b2c3d4e5f.mp4",
  "credits": 190, "tokens": 108900, "costUsd": 0.76, "error": null
}

GET  /videos/seedance/sd-0a1b2c3d4e5f.mp4      the MP4
POST /api/seedance/jobs/sd-0a1b2c3d4e5f/cancel  cancel a queued job (credits back)
GET  /api/seedance/jobs                         your last 200 jobs

Motion video (Claude)

POST /api/design
{
  "businessId": "…", "productId": "…", "photoIds": ["7f0c…"],
  "styleId": "product-hero", "hookId": "auto", "ratio": "9:16", "seconds": 15,
  "note": "Price drop in big 3D letters", "mode": "reference", "versions": 1
}

200 { "jobs": [{ "id": "20261017-1a2b3c4d", "spec": { "scenes": [ … ] }, "status": "designed" }], "error": null }

The answer is the video's design. The studio page draws it and makes the MP4 in the browser, then saves it (POST /api/jobs/{id}/video); the finished file is /videos/{id}.mp4. Edit or extend a design with "mode": "edit" or "extend" and "baseJobId". Templates and hooks: GET /api/options. Products: GET /api/businesses, GET /api/products?business=<id>.

AI image (Nano Banana)

POST /api/image
{ "prompt": "The product from Image 1 on a white marble table, soft morning light", "refs": ["ph:7f0c…"], "ratio": "4:5", "businessId": "…" }

200 { "image": { "id": "up-1a2b3c4d5e6f", "url": "/api/photo/up-1a2b3c4d5e6f", "prompt": "…", "ratio": "4:5" }, "credits": 15 }

GET /api/images     your images, newest first

Up to 3 reference photos. The image is saved as an upload, so up:<id> works as a reference in a video job.

Errors

Every error is JSON with a plain-English message: { "error": "Not enough credits: this needs 190 and you have 40. Top up in Pricing." }.

StatusMeaning
400Something is missing in the request (a prompt, a photo for image-to-video…)
402Not enough credits
404Unknown product, job or file
429Today's test budget is used, or the provider is busy
502The model could not make it (credits given back)
503The model's key is not set yet (Seedance waits for the BytePlus key)
